## 🛠️ Suggested learning paths

<details>
<summary><strong>Backend engineer — from APIs to production</strong></summary>

1. Learn HTTP, Git and SQL using [MDN](https://developer.mozilla.org/), [Git](https://git-scm.com/) and [PostgreSQL](https://www.postgresql.org/docs/).
2. Build an API using [Laravel](https://laravel.com/docs), [FastAPI](https://fastapi.tiangolo.com/) or [ASP.NET Core](https://learn.microsoft.com/aspnet/core/).
3. Document it with [OpenAPI](https://www.openapis.org/) and test it with [Bruno](https://www.usebruno.com/) and [PHPUnit](https://phpunit.de/)/[pytest](https://docs.pytest.org/).
4. Add authentication, validation, rate limiting and security checks following [OWASP](https://cheatsheetseries.owasp.org/).
5. Containerize with [Docker Compose](https://docs.docker.com/compose/) and automate tests with [GitHub Actions](https://docs.github.com/actions).
6. Measure logs, errors and performance using [OpenTelemetry](https://opentelemetry.io/) and [Grafana](https://grafana.com/oss/grafana/).

</details>

<details>
<summary><strong>Frontend engineer — design to deployment</strong></summary>

1. Learn HTML, CSS and JavaScript on [MDN](https://developer.mozilla.org/).
2. Rebuild a [Frontend Mentor](https://www.frontendmentor.io/) design using [Vite](https://vite.dev/) and [React](https://react.dev/).
3. Style with [Tailwind](https://tailwindcss.com/) and test accessibility with [axe-core](https://github.com/dequelabs/axe-core).
4. Add [Playwright](https://playwright.dev/) tests and run [Lighthouse](https://developer.chrome.com/docs/lighthouse/overview/).
5. Deploy to [GitHub Pages](https://pages.github.com/) or [Cloudflare Pages](https://pages.cloudflare.com/).

</details>

<details>
<summary><strong>AI application developer — practical foundations</strong></summary>

1. Experiment with local models using [Ollama](https://ollama.com/).
2. Prototype prompting and retrieval with [Hugging Face](https://huggingface.co/) datasets and models.
3. Explore tool integration with [MCP](https://modelcontextprotocol.io/).
4. Build a small workflow with [LangGraph](https://langchain-ai.github.io/langgraph/).
5. Add evaluation, access control, logging and human approval for consequential actions.

</details>
